# Changelog

## RJMCMCNucleosomes 1.37.1

### BUG FIXES

- [`plotNucleosomes()`](https://adeschen.github.io/RJMCMCNucleosomes/reference/plotNucleosomes.md)
  now plots the nucleosome positions when a `GRangesList` with a single
  element is given.
- [`plotNucleosomes()`](https://adeschen.github.io/RJMCMCNucleosomes/reference/plotNucleosomes.md)
  legend is placed above the plot and each entry is sized to its own
  label so long names are no longer truncated.
- [`splitAsList()`](https://rdrr.io/pkg/S4Vectors/man/splitAsList.html)
  is now imported from `S4Vectors`.

### CODE IMPROVEMENTS

- Native routine registration is generated by
  [`Rcpp::compileAttributes()`](https://rdrr.io/pkg/Rcpp/man/compileAttributes.html);
  the hand-written `init.c` file has been removed.
- Use of [`is()`](https://rdrr.io/r/methods/is.html) instead of
  `class() ==` for class checks.
- Compliance with `BiocCheck` recommendations.
- Continuous integration and test coverage with GitHub Actions.

### DOCUMENTATION

- New Installation section in the vignette.
- Corrections and clarifications in the vignette and the function
  documentation.
- ORCID identifiers added for the authors, and `URL` and `BugReports`
  fields updated.
