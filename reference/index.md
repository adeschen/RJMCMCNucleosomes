# Package index

## Package

- [`RJMCMCNucleosomes-package`](https://adeschen.github.io/RJMCMCNucleosomes/reference/RJMCMCNucleosomes-package.md)
  [`RJMCMCNucleosomes`](https://adeschen.github.io/RJMCMCNucleosomes/reference/RJMCMCNucleosomes-package.md)
  : RJMCMCNucleosomes: Bayesian hierarchical model for genome-wide
  nucleosome positioning with high-throughput short-read data
  (MNase-Seq)

## Nucleosome positioning

Detect nucleosome positions on a segment or on an entire chromosome.

- [`rjmcmc()`](https://adeschen.github.io/RJMCMCNucleosomes/reference/rjmcmc.md)
  : Nucleosome positioning mapping on a segment

- [`rjmcmcCHR()`](https://adeschen.github.io/RJMCMCNucleosomes/reference/rjmcmcCHR.md)
  : Nucleosome positioning mapping on a large segment, up to a
  chromosome

- [`segmentation()`](https://adeschen.github.io/RJMCMCNucleosomes/reference/segmentation.md)
  :

  Split a `GRanges` containing reads in a list of smaller segments for
  the `rjmcmc` function.

## Merging and post-treatment

Merge results from segments and merge closely positioned nucleosomes.

- [`mergeRDSFiles()`](https://adeschen.github.io/RJMCMCNucleosomes/reference/mergeRDSFiles.md)
  : Merge nucleosome information from selected RDS files.

- [`mergeAllRDSFilesFromDirectory()`](https://adeschen.github.io/RJMCMCNucleosomes/reference/mergeAllRDSFilesFromDirectory.md)
  : Merge nucleosome information from all RDS files present in a same
  directory. Beware that only nucleosome information from same
  chromosome should be merged together.

- [`postTreatment()`](https://adeschen.github.io/RJMCMCNucleosomes/reference/postTreatment.md)
  :

  A post-treatment function to merge closely positioned nucleosomes,
  from the same chromosome, identified by the `rjmcmc` function.
